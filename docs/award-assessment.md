# 如果按时提交，大概能拿什么奖？ / If submitted on time, what award?

> 免责声明：以下是对**论文内容本身**的评估，基于国赛（高教社杯）的公开
> 评审尺度与历年获奖分布。最终奖项还取决于**当年同赛区竞争强度、论文
> 写作与排版、省赛/国赛答辩表现**等无法从代码判断的因素，因此给出的是
> **分档预估**，不是保证。

---

## 国赛奖项的层级（从低到高）

```
成功参赛奖  →  省三等奖  →  省二等奖  →  省一等奖
           →  国家二等奖  →  国家一等奖  →  高教社杯（冠名奖，极少数）
```

- **成功参赛奖**：只要按时交、模型自洽、结果合理，基本都给。
- **省三/省二**：模型正确但分析较浅。
- **省一**：模型有亮点、有验证、写作清晰。
- **国二**：模型有高度、有独立验证/灵敏度/不确定性、可视化完整。
- **国一 / 高教社杯**：在国二基础上，建模有原创框架、计算严谨、写作
  达到「可发表」水准，且当年全国前列。

## 分档预估

- **保底：省一等奖。** 内容厚度（框架 + 验证 + UQ + 可视化）已明显超过
  省二/省三 的典型水平。
- **大概率：国家二等奖。** 国二的核心门槛是「有验证、有分析深度、可
  信」，本工作三项全部满足，且覆盖面比一般国二作品更宽。
- **冲击国家一等奖 / 高教社杯需要：** 在「建模原创性」和「写作打磨」
  上再上一层——即 TEDM 框架需要更严谨的数学表述、全文写作达到无瑕疵。
  本工作**具备冲击国一的素材**，但最终能否落地取决于当年竞争与文字
  呈现，不能打包票。
- **不属于「只能拿成功参赛」的情况**：内容完整度远高于该档。

## 对「没提交」这件事的建议

1. **不要因为没有提交就否定这份工作。** 它在内容上已经达到国二量级的
   工程完整度，放到 GitHub 作为作品集，对保研/求职/申请（尤其是
   **金融科技、量化、数据科学**方向，见下面）是实打实的加分项。
2. **把「诚实的局限」当成亮点。** −10.97% 干物质漂移、half-cell 实验
   回退、原始 validate 三项 FAILED——这些在作品集里展示的是你的
   **科学素养**，不是污点。
3. **可以投其他赛事/期刊。** 例如校内数模轮回赛、亚太/美赛（MCM/ICM
   同题型可直接复用框架）、或本科生的计算数学/工程类期刊短文。
