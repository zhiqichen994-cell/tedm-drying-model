# 已知局限与诚实声明 / Limitations (honest disclosure)

这一节把我们在整理代码、加检验时**真实发现**的弱项逐条列出来。
放到 GitHub 上不是减分项——恰恰相反，能主动、定量地指出模型边界，
是评审和招聘方最看重的「科学诚实」。论文本身第 9.2 节也承认了部分局限。

---

## 1. 问题4 移动边界的干物质漂移（−10.97 %）

这是**最值得写进 README 的一条**。

在问题4 的收缩模型里，我们用归一化坐标 `ξ = r/R(t)` 在固定网格上求解，
每步按收缩量更新物理半径。我们用「干物质质量守恒」作为独立诊断：

```
M_dry = ∫ ρ_dry(C) · (1 − C) · 2πr dr     （沿圆柱单位长）
```

数值结果：

```
M_dry(0)            = 3.5027e-01  kg/m
M_dry(end)          = 3.1185e-01  kg/m
dry-matter drift    = -10.967 %   <-- 理论上应为 0
ρ_d(0)   由状态算得 = 278.73 kg/m³
ρ_d(end) 由状态算得 = 689.34 kg/m³
ρ_d 由方程(13)推出  = 774.26 kg/m³
```

**含义**：收缩模型里「干物质密度」前后出现了约 10.97 % 的不一致——
两端的 `ρ_d` 由「体积×浓度」反推，而方程(13) 给出的参考值介于两者之间。
这与论文第 9.2 节承认的「均匀收缩假设」是一回事：收缩只改了几何尺度，
但干物质密度的处理存在近似，导致质量账不闭合。

**怎么呈现**：在 GitHub 上把它作为 `limitations.md` 第一条，并配一张
`M_dry(t)` 曲线图（README 的「Limitations」小节已引用）。这比硬说
"完全守恒" 可信得多。

## 2. 我们放弃的一个「改进」实验（half-cell 表面格式）

整理时我们一度想给表面单元加一个半宽（`half-cell`）高精度对流格式，
以为能进一步压低近表面误差。实测结果反而**更差**：

```
引入 half-cell 后：水分相对 L2 由 7.85e-05 → 9.86e-04
观测阶由 ≈2 → ≈1
```

**原因**：最外层节点本来就精确落在 `r = R` 上，`T[N]` 就是边界值，
无需重建。强行加半宽格式反而破坏了这一定位。我们把这个实验**回退**，
并在 `model.py` 的注释里写明「Node N sits exactly on r = R」。这条
也值得写进文档：它说明我们不是无脑堆格式，而是用误差测量来验证每个
选择的合理性。

## 3. 原始 `validate_q4` 的三项 FAILED

原始代码里的 `validate_q4.py` 报告了**三项全部 FAILED**：

```
质量守恒检查：10.97 %   （即上面的干物质漂移）
能量守恒检查：69.08 %
边界通量检查：136 %
```

注意：这三项用的是原始（有缺陷的）度量定义，其中部分「FAILED」来自
**符号约定不统一 + 量纲混用**，我们重写 `conservation.py` 后已经修正
（见 `docs/verification.md` 问题1 的 1e-13 残差）。但**干物质那条 −10.97%
是真实的物理/建模局限**，无法靠改诊断消除——所以保留在 limitation 里。

## 4. 其他被承认的简化

- **一维径向简化**：忽略轴向热质传递（依赖 `L ≫ R` 假设）。
- **均匀收缩假设**（问题4）：收缩按同一比例作用于全部半径，未考虑
  各向异性或非均匀收缩。
- **降速段经验式**：`D(C)` 用 `exp(−B/C)` 经验式，未做微观孔道验证。
- **附件数据为连续时序**：附件1 是 241 行、1 分钟分辨率的实测温湿度
  时序，不是 9 个设定点；我们用 `np.interp` 做保持平台的外推。

## 5. 这些局限对「投稿能拿什么奖」的影响

**几乎没有负面影响**。国赛评审看的是：模型是否自洽、是否有独立的
验证手段、是否能诚实讨论局限、是否有不确定性量化。本工作的薄弱环节
（移动边界质量账、一维简化）是**该问题本身的公认难点**，能在论文里
把账算清、把漂移量定量报出来，反而比「假装完美」得分高。详见
`docs/award-assessment.md`。
