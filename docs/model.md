# 模型说明 / Model description

本仓库复现的是 **2026 高教社杯全国大学生数学建模竞赛 A 题「药材的烘干」**
的计算工作。题目给定一个圆柱形药材（长 `L = 25 cm`，半径 `R = 2 cm`，
初始温度 `T₀ = 28 ℃`，初始水分浓度 `C₀ = 2.55 kg/kg`），要求把中心/表面
温度、水分浓度随时间和半径的分布算出来，并把整体水分降到
`C < 0.15 kg/kg`。

团队用一条统一框架贯穿四个子问题，并命名为 **TEDM（退潮模型，
Tide-Ebbing Drying Model）**，其口诀是：

> **热波先行、湿潮滞后、中心定终点、收缩改尺度。**

---

## 1. 控制方程

在圆柱几何下做轴对称、只沿径向 `r` 的一维简化（长度 `L ≫ R`，轴向
通量可忽略）。每个子问题都是同一组耦合方程，只是物性参数不同：

**能量方程（温度 `T`）**

```
ρ·cp · ∂T/∂t = (1/r) · ∂/∂r ( r · k · ∂T/∂r )          # 内部传导
-k · ∂T/∂r |_{r=R} = h · (T_s − T_air)                 # Robin 对流边界
```

**质量方程（水分浓度 `C`）**

```
∂C/∂t = (1/r) · ∂/∂r ( r · D_conc(C,T) · ∂C/∂r )       # 内部扩散
-D_conc · ∂C/∂r |_{r=R} = k_m · (C_s − C_air)          # Robin 蒸发边界
```

其中水分扩散系数随含水率剧烈下降（典型的「降速干燥」材料）：

```
D_conc(C, T) = D0 · exp(−B / C) · exp( −Ea/Rg · (1/T − 1/T_ref) )   # Arrhenius
```

- `附录2`（问题1/2 初版）：`D0 = 7e-9`，`B = 0.89`，常数物性。
- `附录3`（问题2 进阶）：`ρ, cp, k` 随 `C` 线性变化，`D0 = 2.4e-3`，
  `B = 0.45`，并引入 Arrhenius 温度修正（`Ea = 3850`）。
- `附录4`（问题4）：另一组物性，含体积收缩。

完整参数表见 [`../data/`](../data/) 与论文原文附录 2/3/4。

## 2. 数值方法

| 组件 | 选择 | 原因 |
|------|------|------|
| 离散 | 有限体积法（FVM） | 天然满足离散守恒，便于做 V&V |
| 时间 | 后向欧拉（隐式） | 无条件稳定，容许大时间步 |
| 非线性 | Picard 迭代（lagged diffusivity） | 解耦 `D(C,T)` 的强非线性 |
| 求解 | 三对角带状矩阵 `scipy.linalg.solve_banded` | `O(N)` 一次扫描 |
| 平均 | 圆柱体积加权 `∫ r·(·)dr / ∫ r dr` | 中心单元小、外环大 |

空间网格：把半径分成 `N_R = 100` 个等宽控制体，节点落在单元中心；
**最外层节点 `N` 精确落在 `r = R` 上**，因此表面值 `T[N]` 就是边界值，
无需外推重建（这一点我们专门验证过，见 `docs/limitations.md`）。

时间步：问题1/2 用 `dt = 1 s`；问题3/4 用 `dt = 60 s`（由事件时间尺度决定）。

---

## 3. 四个子问题的差异

| 子问题 | 物性集 | 关键特征 | 主要输出 |
|--------|--------|----------|----------|
| Q1 | 附录2（常数） | 30 min、实测温湿度曲线 | 中心/表面温度、表面水分 |
| Q2 | 附录3（变物性+Arrhenius） | 3 h、热-质强耦合 | 中心/表面温度与水分 |
| Q3 | 附录3 | 50 ℃ 平台，干燥到 `C<0.15` | 干燥时间 `τ ≈ 57.22 h` |
| Q4 | 附录4 | **体积收缩** `R: 2.0→1.2 cm`，移动边界 | `τ ≈ 50.87 h`，比定半径快 60.6% |

**问题4 的移动边界**：用归一化坐标 `ξ = r/R(t)`，在固定 `ξ` 网格上求解，
每步按收缩量更新物理半径；质量守恒在「干物质质量」意义上诊断（见
`docs/limitations.md` 中发现的 −10.97% 漂移项）。

## 4. 代码结构

```
tedm/
  config.py            # 所有常数与文件路径
  properties.py        # PropertySet：三套物性（附录2/3/4）
  model.py             # 网格、三对角求解、温度/水分单步
  solver.py            # 问题1 固定域求解器（支持 n_cells / radius 覆盖）
  solver_q2.py         # 问题2 变物性求解器
  solver_q3.py         # 问题3 事件时间求解器
  solver_q4.py         # 问题4 移动边界求解器
  solver_q4_fixed.py   # 问题4 定半径对照组
  data_loader.py       # 读附件1（温湿度时序）/ 附件2（半径时序）
  postprocess*.py      # 生成 result1..4.xlsx 与 表1..表6.xlsx
  viz/q1..q4.py        # 32 张图
  analysis/
    conservation.py    # 离散守恒 + 极值原理 + 干物质诊断
    verification.py    # 与 Bessel 级数解析解对比
    convergence.py     # QoI 的网格/时间步收敛
    sensitivity.py     # 参数敏感性（龙卷风图）
    robustness.py      # 稳健性
    uncertainty.py     # 蒙特卡洛不确定性量化
    pareto.py          # 时间–能耗 Pareto 权衡
tests/                 # pytest 套件（133 项，已全绿）
```

入口：

```bash
python scripts/run_all.py            # 全部求解 + 制表 + 绘图 + V&V
python scripts/run_all.py --fast     # 跳过验证/收敛研究
python -m tedm.viz.q1                # 单独画某题的图
pytest                               # 跑全部测试
```
